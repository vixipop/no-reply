# No Reply — Feature Build List

Living checklist. We build **one at a time**, in order; after every couple of
features I show this list back with items checked off.

**Status:** `[x]` done · `[~]` partially there / needs upgrade · `[ ]` not started

> **North-star reward:** the only reply you ever get is from *yourself, later.*
> Every feature below serves one of three feelings — **the exhale** (it's out,
> it's safe), **the reply from you** (past-you talks back), **becoming someone**
> (you're staying sharp). See CONTEXT.md / VISION for the full why.

---

## 1. Capture & the exhale — "it's out of my head, and it's safe"
- [x] Frictionless chat-style input (no blank-page cursor)
- [x] Choose a prompt or write your own title
- [ ] Save-as-exhale — entry visibly drops/seals into the void (not "sent")
- [ ] Quiet, rotating save microcopy (no success toast)
- [ ] Reassuring placeholder ("start typing… no one's reading")

## 2. The reply from yourself — the core reward
- [ ] "A reply came in" card on open (surfaces a past entry)
- [ ] Reply-to-past-you threading — write back to old entries ⭐ hero feature
- [ ] On-this-day / resurfacing engine

## 3. Becoming someone — kind streak, not a punishing one
- [~] Streak counter (exists; needs identity + kindness reframe)
- [ ] Weekly grace day (one miss doesn't reset it)
- [ ] Identity + anti-AI streak copy ("days you didn't let a bot think for you")
- [ ] Gentle "welcome back" after a lapse (never shame)

## 4. The mirror — weekly stats, never verdicts
- [~] Rolling weekly entry count (exists)
- [ ] Hours-written tracking
- [ ] Weekly recap screen (hours, days shown up, top prompt, a repeated word)
- [ ] "We won't tell you what it means — that's your job" framing

## 5. Archive / time machine — investment made visible
- [x] Archive of all entries (cards)
- [x] Search + this week/month/year filters
- [x] Delete entries
- [x] Fully editable entries (title, text, photos, cover)
- [x] Preserve indents / paragraphs / blank lines
- [ ] "Everything you've told no one" framing + kept-count
- [ ] Flag on-this-day entries in the archive

## 6. First week — where people are actually lost
- [ ] 60-second first-write onboarding
- [ ] Day-2 forward hook (shown after first save)
- [ ] Self-set gentle nudge — the one opt-in notification ("i'll whisper, not shout")

## 7. Prompts — the anti-blank-page tool
- [~] Prompt rotation on scroll (exists; dummy set)
- [ ] Expand prompt library, grouped by mood (quick / rage / gratitude / clarity / future / therapy)

## 8. Voice & content
- [ ] Manifesto / hero line
- [ ] In-voice microcopy pass across the whole app (lowercase, honest, no corporate)

## 9. Delight & paid tier — later
- [ ] Turn an entry into a shareable image/card
- [ ] Stickers + backgrounds (paid)
- [ ] Background removal for uploaded stickers

## 10. North star — v2
- [ ] Hivemind whiteboard — you connect your own notes into a visual web
